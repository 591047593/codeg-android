### 更新内容

- App 更新下载新增 gh-proxy.com、ghfast.top、ghproxy.net 三条公共代理，并保留 GitHub 直连作为候选。
- 下载前并行试读相同大小的 APK 样本，按本次实测耗时选择最快的可用线路；弹窗显示测速、当前下载线路及校验状态。

### 修复内容

- 线路完整下载失败、长度异常或摘要不符时，会清理半包并尝试其它已测通的线路，避免始终卡在同一个下载地址。
- 使用独立 GitHub API 提供的 SHA-256 校验完整包，不把代理返回的 APK 与其自行提供的校验值互相当作可信证明。
- 增加快慢线路、假 HTML、Range 忽略、断线、篡改、超时及取消的回环 HTTP 回归测试。
- 完整包下载采用按包大小计算的独立时限，避免把正常慢速下载误当成短时测速超时。

测速每条线路最多等待 6 秒、试读最多 64KiB；测速只代表当前网络样本，公共代理可用性可能变化。代理只接收本仓库公开更新包地址，不携带 Codeg 登录 Token 或 Cookie。已有旧版首次安装此版本仍需使用旧下载方式或手动安装，此版本之后的更新才会使用新选路逻辑。
