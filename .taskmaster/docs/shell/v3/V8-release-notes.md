### 更新内容

- 更新下载加入 GitHub 直连及三个公共代理的小样本实测选路，下载失败自动尝试测通的备用线路，保留独立可信 SHA-256 校验。
- 更新弹窗支持取消下载，显示当前线路、百分比及已下载大小；服务器管理页与首次配置页新增手动检查更新入口。
- 设置、提交、导入会话等独立页面的顶部返回和关闭操作，可一次回到进入前记录的工作区；系统返回仍逐级处理。

### 修复内容

- 修复通知桥默认端口来源比较及跨线程访问问题，通知权限包含系统与渠道状态；新通知点击在冷启动时按保存的服务器和网页目标恢复，不再依赖已经消失的旧网页回调。
- 修复原生剪贴板兜底绕过浏览器权限拒绝的问题；读取要求明确的用户操作，原生管理页覆盖时不允许后台网页访问剪贴板。
- 打开服务器管理页不再销毁当前 WebView；初始化异步读取服务器配置，失败提供重试且不清空数据。
- 修复自动重连不断打断慢加载的问题，多种重试入口共享加载互斥与超时控制；服务器连接检查区分需要登录、HTTP 错误及未识别页面。
- 检查更新失败只短暂退避，不再误等六小时；下载失败分类提示，混合线路失败不会隐藏已发生的摘要不一致。
- 新增通知、剪贴板、导航、更新策略与下载、恢复门禁和服务器响应分类回归测试；保留手机窄屏实时 tok/s 显示修复。

本次不包含断点续传、进程退出后的常驻推送或服务端改造。旧版本首次升级仍使用旧下载方式或手动安装；新下载选路在安装本版本后生效。自动化测试和 CI 构建不替代 Android 16 真机验收。
