## 范围说明

- 通知点击在**冷启动**（App 已被杀）时，壳会在页面加载完成后补投 `onclick`；
  用例 V5-05 分别在"后台"和"杀掉后"各做一次。
- 弹层的识别依赖 `data-slot`/`data-state`/`data-open`；网页改版会打破它，
  届时优先检查 `src/components/ui/*.tsx` 的 slot 名是否变化。
