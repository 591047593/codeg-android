## 1. 目标信息架构（第一性原理）

产品本质 = **多设备 agent 编排的"宏观委派 + 微观干预"终端**（macro delegation, micro steering）。最高频的四类意图：看状态（动态）、存想法（收件箱）、管任务（任务板）、调配置（设置）。会话/文件夹/搜索是**手段**而非终点——从工作台按需进入。因此：

### 1.1 底部导航（严格四栏，新任务书 §一.2）

| 路由（不变） | 标签 | 内容 |
|---|---|---|
| `activity` | 动态 | **工作台**（单页，去三子页） |
| `inbox`（新增） | 收件箱 | 现 InboxScreen 原样晋级 |
| `tasks`（新增） | 任务板 | 现 TaskHubScreen 原样晋级 |
| `settings` | 设置 | 现 SettingsScreen 不动 |

### 1.2 降级为 push 路由（能力零删减，审查修订①⑥）

- `chats`（会话列表）/`folders`（文件夹）/`search`（搜索）**路由字符串原样保留**，从 tab 集合移出，改为全屏 push 目的地（同 NavHost，**底栏隐藏但 GlobalDeviceBar 保留**——三屏定义为"带设备栏的 push 面"：`showDeviceBar = route ∈ 四栏 ∪ {ROUTE_CHATS, ROUTE_FOLDERS, ROUTE_SEARCH}`；MainShell:728-730 的 allSelected/showAll 判定同步改用新常量）。Back=回到来源面（push 语义自然回退）。
- push 全部 `launchSingleTop=true` 防重复栈（审查修订⑤）；「查看全部会话」push 前先置 `chatsAll=true`（聚合会话能力从工作台一键可达）。
- 三屏内部能力（聚合列表/长按菜单/目录浏览/克隆/搜索历史）**一行不动**。入口：
  - **会话**：工作台「正在运行」区头"查看全部"（置 chatsAll）+ 快捷入口行「会话」卡 + 悬浮球动作 tabChats。
  - **文件夹**：工作台快捷入口行「项目」卡。
  - **搜索**：工作台顶部全局搜索条 + 悬浮球面板「全局搜索」行 + quickSearch 动作。
- **folders 设备滑动手势退役**（审查修订⑦）：滑动手势门控在 tab 路由上，folders 降级后手势自然失效；诚实移除 GeneralScreen 的 folders 开关与 `DeviceSwipeScope.DEVICES_ONLY` 分支（含其单测的对应断言），activity 手势（WITH_ALL）保留。

### 1.3 工作台布局（对齐 ui1/ui2，真实数据禁假数）

自上而下：全局设备栏（不动）→ 统计行（运行中 N / 需要处理 N / 在线设备 N，真实 poll）→ 快捷入口行（会话/项目/搜索 卡 + 新建会话主按钮）→ 「正在运行」会话卡（现有 feed running 段，区头"查看全部"→chats）→ 「需要处理」任务预览 ≤3 条（点击跳任务板 tab）→ 「最近活动」24h feed（现有）。

### 1.4 悬浮球快捷面板（改造重点，新任务书 §三/§三.6）

- **单击=展开/收起快捷面板**；拖动=移动+贴边+记忆位置（现有，1s hold=拖动预备**保持不变**——新任务书 §5.2 的"长按=配置"**有意不采纳**，避免破坏移动语义；配置入口=面板「全部动作」行 + 设置页）。
- 面板内容（对齐 ui1）：2×2 大卡【新建会话（快速开始）/ 记录想法（保存灵感）/ 创建任务（派发任务）/ 会话交接（转移工作）】各带一行辅助说明 + 底部「全局搜索」行 + **「全部动作」行**（打开现有全量动作列表——theme/accent/字号/切机等 21 动作不失可达，审查修订⑧）。
- 新增动作 id：`quickIdea`/`quickTask`/`quickHandoff`/`quickSearch`（`newSession` 复用现有）。现有 21 动作与用户自定义绑定**全部保留**，四项新动作进入绑定选择器。
- 快捷记录想法：`QuickIdeaSheet`（标题可空自动生成"想法 MM-dd HH:mm"/描述/保存/取消），不要求选设备项目，存 IdeaStore → 收件箱可见。
- 快捷创建任务：直接打开派发表单（task 模式默认、无想法来源），**不经过收件箱**。
- 快捷会话交接：最近会话选择 sheet（真实聚合列表）→ 单飞 handoffTo(serverId) → 打开会话详情并经 `HandoffAutoOpenBus` 自动展开 HandoffSheet（复用 v141 全部真实数据管线，不伪造模板）。

### 1.5 统一选择器（新任务书 §六：单列 + Chips + BottomSheet，灭滚轮）

新组件（core/designsystem/component/）：`PickerField`（表单行：图标+标签+当前值+chevron）、`DeviceChipRow`（目标设备横滚 chips，在线状态）、`AgentChipRow`（横滚 chips，首位"自动"）、`OptionListSheet`（垂直列表 BottomSheet，搜索+选中态）。

- **派发表单重建 = 自包含 `DispatchForm`**（状态+回调接口驱动，**双宿主**，审查修订②）：
  - 宿主 A：收件箱想法派发（InboxViewModel 供状态，保留 UNKNOWN 卡/账本联动）。
  - 宿主 B：悬浮球快捷建任务（新 `QuickActionViewModel`：目标加载+默认值预选+DispatchService.send+结果面；UNKNOWN 恢复仍由收件箱 tab 的账本卡兜底——账本是全局的）。
  - 字段顺序（doc1 §6.1）：执行方式（会话/任务卡）→ 设备 chips → Agent chips → 项目 PickerField(OptionListSheet) → 分支（仅任务模式，默认"跟随项目分支"）→ 标题 → 描述 → 定时（仅任务模式）→ **派发摘要卡**（全量回显）→ 底部固定主按钮（**会话模式文案「创建会话」/任务模式「创建任务」**，doc1 §6.7）。
  - **v146 不变量搬运清单**（审查修订③，重建时逐项核对，审查维度含此项）：进程死亡恢复 LaunchedEffects（设备/项目/Agent 失效重校验 InboxScreen.kt:620-643）、branchFresh 键控（:610-619）、过期选择文件夹检查（InboxViewModel.kt:320-324）、过去时间 30s ticker（:596-605）、sheet 拖动锁（v148）、结果对话框在 Screen 层（v146 B-7）、rememberSaveable 键、派发默认值预选（:663-687）、canDispatch 门禁、UNKNOWN 三重门禁。
- **HandoffSheet**：六字段+中继 chips 不动，三滚轮 → 统一选择器（自含 VM 已成立，无归属问题）。
- **composer**：文件夹 DropdownMenu → OptionListSheet（延迟创建模型不动）。
- WheelColumn 组件保留（零调用点后不删，测试保留钉几何契约）。

## 3. 红线（新任务书 §十四 + 主人常设约束）

不新增中央服务器/独立数据库；不改 Rust 服务端核心；不自建第二套任务状态机/调度器；不绕开 Codeg 原生 API；不破坏多服务器配置；日志无 Token；敏感配置不进截图/报告；**不因 UI 优化删除任何现有功能**（chats/folders/search 能力逐条可达性验收；面板保留全量动作入口）；未知任务状态绝不归已完成；本地零编译零测试运行（CI 编译验证）；token/密钥只在本地 shell。

## 4. 验收硬指标（新任务书 §十五最终验收原则）

1. 任意页面 ≤2 次点击记录想法（球→记录想法→保存）。
2. 任意页面 ≤2 次点击新建会话（球→新建会话）。
3. 不进收件箱即可创建任务（球→创建任务）。
4. 工作台一屏回答"所有设备在干什么"（统计+正在运行+需要处理）。
5. 需要人工处理的任务一眼可见（统计卡+预览+任务板等你处理段）。
6. 设备/项目/Agent 选择统一为 chips+BottomSheet，无滚轮。
7. 会话列表/文件夹浏览/搜索/悬浮球自定义动作/主题/手势/多服务器切换全部可达可用。
8. 未知状态不归完成（TaskBoard 原语义不变）。
